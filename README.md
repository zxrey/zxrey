## 🚀 Featured Projects

### Predicting Customer Dissatisfaction in a Brazilian E-Commerce Marketplace

**Code:** [e-commerce-olist-customer-satisfaction](https://github.com/zxrey/e-commerce-olist-customer-satisfaction)

**Goal:** To determine whether orders at risk of a bad review can be flagged before delivery happens, using only information available at the moment of purchase.

**Description:** The project analyzed ~100k orders from the Olist Brazilian E-Commerce dataset across 9 relational tables. It involved joining and cleaning the tables into a single order-level dataset, engineering features such as delivery delay and seller-customer distance, performing exploratory data analysis on delivery and satisfaction patterns, and building a leakage-free predictive model using only pre-delivery information (logistic regression → XGBoost), with SHAP-based interpretability.

**Skills:** data cleaning, feature engineering, exploratory data analysis, predictive modeling, model interpretability.

**Technology:** Python, Pandas, NumPy, scikit-learn, XGBoost, SHAP, Matplotlib.

**Results:** The model reached a ROC-AUC of 0.613 and PR-AUC of 0.198 (vs. a 0.11 no-skill baseline). The analysis also found that late delivery is by far the strongest driver of bad reviews, and identified specific regions and product categories as the highest-impact targets for improvement.

### Game-On — Semantic Video Game Search Engine

**Code:** [Game-On-Project](https://github.com/zxrey/Game-On-Project)

**Goal:** To build a search engine that lets anyone find a game matching their mood or interests by typing a natural-language query in English or Spanish, instead of navigating tags and filters.

**Description:** The project analyzed a dataset of ~30,000 Steam games. It involved cleaning and grouping relevant game features, generating multilingual sentence embeddings to enable semantic (rather than keyword) search, enhancing raw user queries with an LLM before matching, and combining semantic similarity with a game-quality signal (reviews, Metacritic score) to rank results. Built as a 4-person team final project for the Le Wagon Data Science & AI Bootcamp.

**Skills:** NLP, semantic search, embeddings, prompt engineering, API development, data cleaning.

**Technology:** Python, Sentence Transformers, Groq LLaMA 3, Pandas, NumPy, FastAPI, Streamlit.

**Results:** Delivered a working multilingual search API with a live demo, returning top-5 game matches with match %, AI-generated explanations, real-time pricing, and Steam integration.
